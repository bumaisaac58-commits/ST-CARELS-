1. About the System

The St Carels School Management System is an online platform designed to simplify school administration, improve record keeping, and support academic management.

The system is designed for use by school administrators, teachers, and other authorized school staff.

2. Main Features

- Administrator Login and Dashboard
- Student Registration and Management
- Teacher Management
- Class Management
- Subject Management
- Examination and Marks Management
- Academic Reports
- Timetable Generator
- School Settings
- Secure Login and Logout
- Mobile-Friendly Interface

6. Installation and Setup

1. Create a GitHub repository for the project.
2. Upload the project files.
3. Configure your Supabase project and database tables.
4. Configure Supabase authentication.
5. Connect the website to Supabase using your project URL and public publishable key.
6. Enable GitHub Pages in the repository settings.
7. Open the published website using its GitHub Pages address.

7. Security

- Use Supabase Row Level Security (RLS) to protect school records.
- Never publish your Supabase service-role key in browser JavaScript.
- Restrict access to sensitive school information.
- Use appropriate authentication and authorization rules.
