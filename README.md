Welcome to the St Carels Umoja Kwanza School Management System. This system is designed to simplify school administration, improve academic management, and support teachers, learners, and school administrators.

1. About the System

The St Carels School Management System is a web-based platform designed to manage school activities efficiently.

It supports school administration, student registration, teacher management, examinations, and academic reporting.

2. Main Features

- Dashboard: View school statistics and important information.
- Student Management: Register, view, edit, and manage students.
- Teacher Management: Manage teacher information and assignments.
- Class Dashboard: View class information and academic progress.
- Examination Management: Enter examination marks and manage assessments.
- Academic Reports: Generate and view student performance reports.
- School Settings: Configure school information and system preferences.
- Secure Login: Allow authorized users to access the system.
- Database Integration: Connect the system to Supabase for online data storage.

6. How to Open the System

1. Upload the project files to your GitHub repository.
2. Open the repository settings.
3. Select Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select the "main" branch and "/ (root)" folder.
6. Click Save.
7. Wait for GitHub Pages to publish your website.
8. Open the website link provided in the Pages section.

Ensure that "index.html" is located in the root folder of your repository.

7. Database Configuration

The system can use Supabase to store and manage school data.

To connect Supabase:

1. Create a project in Supabase.
2. Create the required database tables.
3. Copy your Supabase project URL.
4. Copy your Supabase publishable key.
5. Configure the credentials in "supabase.js".
6. Configure appropriate database permissions and Row Level Security (RLS) policies.

Security: Never place a Supabase secret key or service-role key in publicly accessible JavaScript files.
