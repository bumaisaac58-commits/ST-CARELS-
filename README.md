📚 About the System

The St Carels School Management System is a modern school administration system designed to help the school manage academic, administrative and learner information efficiently.

The system is designed for use by school administrators, teachers and other authorized staff.

🎯 Main Objectives

- Simplify school administration
- Manage teachers and support staff
- Manage learners and classes
- Record and manage examination marks
- Generate academic reports
- Manage subjects and subject allocation
- Manage class teachers
- Manage school information
- Improve communication and record keeping
- Reduce paperwork and manual data entry

🔐 Security

The system should use secure user authentication and role-based access.

Possible user roles include:

- Administrator
- Headteacher
- Deputy Headteacher
- Teacher
- Support Staff

Users should only access information appropriate to their role.

💾 Database

The online version can use Supabase for:

- Authentication
- School accounts
- Teachers
- Students
- Classes
- Subjects
- Marks
- Timetables
- School settings

🌐 Online Version

The online version can be hosted using GitHub Pages or another web-hosting service and connected to Supabase for cloud data storage.

💻 Offline Version

An offline version can also be developed so that the school can use the system without an internet connection.

The offline version can store information locally on the computer and synchronize with an online database when internet access becomes available.

🚀 Getting Started

1. Download or clone the project.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. For the online version, configure the Supabase connection.
5. Create the administrator account.
6. Complete the school setup.
7. Add teachers and students.
8. Add subjects and classes.
9. Begin entering academic information.
